# Предрегистрация эксперимента 004 — позиционирование рынка (фандинг, открытый интерес, лонг/шорт)

Записано **до** запуска. Данные цены, разбиение DEV / VALIDATION / HOLDOUT, издержки, правила
движка, размер позиции и критерии отбора — как в preregistration-001. HOLDOUT не открыт.
Накопительный счёт попыток: 169 + **64** = **233**.

## Зачем
Эксперименты 001–003 использовали только цену и объём и не нашли преимущества после издержек.
Здесь впервые используется **позиционирование участников** — то, что двигает фьючерсный рынок:
перекос фандинга, приток/отток открытого интереса, расхождение крупных и мелких трейдеров.

## Данные позиционирования
- Источник: публичный архив Binance USDⓈ-M `data.binance.vision` (крупнейшая площадка
  бессрочных фьючерсов; её позиционирование — сигнал для всего рынка, сделки — на Bybit).
- `metrics` (шаг 5 минут): открытый интерес (`oi`), лонг/шорт топ-трейдеров по позициям
  (`top_pos_ls`), лонг/шорт всех аккаунтов (`acc_ls`). BTC с 2021-01, ETH с 2021-12.
  В 2022 году ~87 % пропусков у лонг/шорт-рядов — на этих участках сигналов нет.
- `fundingRate`: каждое начисление фандинга.
- **Причинность:** решение на закрытии бара использует только строки metrics со временем
  ≤ закрытие − 5 минут (запас на задержку публикации) и начисления фандинга со временем ≤ закрытие.
  Значение старше 1 часа (metrics) или 12 часов (фандинг) считается пропуском.
- Процентили считаются по скользящему окну **90 дней**, включающему только прошлое и текущий бар.

## Общие правила
- Фильтр ФРС (принят в эксперименте 003 как защитное правило) включён во всех вариантах.
- Стоп k·ATR14 текущего таймфрейма; фильтр издержек (стоп < 0.25 % — пропуск) как раньше.
- Одна позиция на стратегию и инструмент, выход по стопу, тейку (если есть) или по времени.

## Гипотезы

**H-011 FUND-FADE (4h).** Экстремальный фандинг = толпа перегружена в одну сторону и платит
за это; ожидается откат против толпы. Процентиль текущего фандинга в 90-дневном окне > q →
шорт; < 1 − q → лонг.
Сетка: q ∈ {0.90, 0.97}; удержание ∈ {24, 72} ч; k ∈ {2, 3}; тейк ∈ {нет, 2R} → 16.

**H-012 OI-BREAKOUT (4h).** Пробой экстремума N баров подтверждён притоком новых денег:
изменение OI за последние 24 ч выше своего 90-дневного процентиля p. Вход по пробою.
Сетка: N ∈ {12, 24}; p ∈ {0.5, 0.8}; фильтр тренда EMA-200 ∈ {выкл, вкл}; удержание ∈ {24, 72} ч;
стоп 2 ATR, тейк 2R → 16.

**H-013 FLUSH-FADE (1h).** Принудительное закрытие позиций (ликвидации, сквизы): резкое
движение цены за W часов (|доходность| выше 90-дневного процентиля pct) одновременно с резким
падением OI (изменение OI ниже процентиля 1 − pct). Вход против движения — после вынужденных
продаж/покупок цена возвращается.
Сетка: W ∈ {4, 24} ч; pct ∈ {0.90, 0.97}; удержание ∈ {8, 24} ч; k ∈ {2, 3}; тейк 2R → 16.

**H-014 TOP-VS-CROWD (4h).** Крупные трейдеры против толпы: d = z(log top_pos_ls) − z(log acc_ls)
(z — по 30-дневному окну). d > thr → лонг (крупные длиннее толпы), d < −thr → шорт.
Сетка: thr ∈ {1, 2}; удержание ∈ {24, 72} ч; k ∈ {2, 3}; тейк ∈ {нет, 2R} → 16.

Всего вариантов: **64**.

## Выбор и критерии
Без изменений (preregistration-001): лучший по t-статистике вариант каждой гипотезы на DEV
(≥ 200 сделок, среднее > 0; для этих медленных гипотез порог снижен до **≥ 60 сделок**, так как
4h-сигналы редки — записано до запуска), затем VALIDATION (среднее > 0 на обоих инструментах,
t ≥ 2.0, PF ≥ 1.1, ≥ 30 сделок), затем HOLDOUT один раз (среднее > 0, PF ≥ 1.05, устойчиво к
издержкам ×1.5).

## Ограничения, известные заранее
- Для живой торговли понадобится тот же поток данных в реальном времени (Binance futures API
  или эквивалент Bybit); это задача после успешной валидации.
- Удержание до 72 ч выходит за рамки «внутри дня»: издержки ~13 bps на круг требуют движений
  крупнее внутридневных; владелец согласен на демо-проверку.
