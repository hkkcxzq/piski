# Предрегистрация эксперимента 003 — тренд внутри дня и фильтр заседаний ФРС

Записано **до** запуска. Данные, разбиение DEV / VALIDATION / HOLDOUT, издержки, правила
движка, размер позиции и критерии — как в preregistration-001. HOLDOUT не открыт.
Накопительный счёт попыток: 80 + 64 + **25** = **169**.

## Гипотезы

**H-009 TSMOM (1h).** Направление позиции = знак доходности за последние L часов; выход по
времени через H часов (не дольше суток) или по стопу k·ATR14; тейк-профита нет — тренду дают
идти до выхода по времени. Механизм: медленное распространение информации и поведение толпы
(догоняющие покупки/продажи) создают автокорреляцию доходностей на горизонте дней.
Сетка: L ∈ {24, 72, 168} ч; H ∈ {8, 24} ч; k ∈ {2, 4}; фильтр ФРС ∈ {выкл, вкл} → 24 варианта.

**H-010 BRK-TREND-FOMC (4h).** Лучший «почти прошедший» вариант эксперимента 002 (пробой
24-барного экстремума по EMA-200, стоп 2 ATR, тейк 2R) с фильтром ФРС. Один вариант.
Это прямая проверка идеи «фильтр событий улучшает стратегию».

## Фильтр ФРС (новости по расписанию)
Сигнал пропускается, если позиция, открытая по нему, была бы открыта в окне
**[решение ФРС − 12 ч; решение ФРС + 2 ч]**. Время решения — 14:00 по Нью-Йорку во второй день
заседания; даты заранее публичны, фильтр не заглядывает в будущее.

CPI и NFP не включены: историческое расписание нужно брать из проверенного источника (BLS),
а исследовательская среда к нему не имеет доступа. Их добавим, когда календарь будет собран на
компьютере владельца.
