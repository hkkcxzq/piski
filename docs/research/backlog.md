## H-016 · Управление выходом для swing-mom (подтягивание стопа / частичный тейк)
*Записано 2026-10-12 по просьбе владельца.*

**Проблема.** У `swing-mom` нет тейка и нет подтягивания стопа: выход только по исходному стопу
(≈ 3 дневных σ) или через 14 дней. При хорошем тренде часть прибыли может быть отдана обратно
до выхода по времени.

**Варианты для проверки (заранее фиксированный короткий список):**
1. **Chandelier-стоп:** стоп подтягивается за ценой на k·σ_d от максимального закрытия с момента
   входа (для шорта — от минимального), только в сторону уменьшения риска; k ∈ {2, 3}.
2. **Безубыток после +1R:** когда прибыль достигла 1R, стоп переносится на цену входа.
3. **Частичный тейк:** 50 % позиции закрывается на +2R, стоп остатка — в безубыток, остаток
   держится до 14 дней.
Базой для сравнения служит текущая `swing-mom` без изменений.

**Почему нельзя проверить «как обычно».** Параметры `swing-mom` выбраны на DEV/VALIDATION,
а HOLDOUT уже израсходован (эксперимент 006). Подбор выхода на тех же данных = подгонка.

**Как проверять честно (два независимых источника):**
- **Теневая торговля на демо:** движок торгует базовую версию, а варианты 1–3 считаются
  «в тени» на тех же живых 4h-свечах начиная с 2026-10-01 (без реальных ордеров). Сравнение —
  после ≥ 30 закрытых сделок базовой версии.
- **Другие инструменты:** парное сравнение «база vs вариант» на монетах, где стратегия никогда
  не настраивалась (SOL, BNB, XRP, DOGE, …, 2021–2026). Торговать ими при этом не обязательно.

**Критерий принятия:** вариант лучше базы по средней сделке в R и не хуже по максимальной
просадке на обоих источниках; иначе остаётся текущая версия.

## H-017 · «ИИ-риск-офицер»: польза новостных решений модели
*Записано 2026-10-12.*

Модель (Claude) читает новости и может только снижать риск (осторожность, пауза, закрытие).
Проверка только вперёд во времени: исторический бэктест загрязнён тем, что модель знает, чем
закончились прошлые события. Метрика: после пауз/закрытий по решению модели рынок в среднем
двигался сильнее обычного (волатильность за 1–6 ч после решения vs без решения) и решения не
стоили стратегии больше, чем сэкономили. Оценка — после 2–3 месяцев журнала `assessments.jsonl`.
