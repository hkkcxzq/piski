# Предрегистрация эксперимента 006 — открытие HOLDOUT для свинг-моментума

Записано **до** открытия HOLDOUT (2025-07-01 — 2026-09-26). Период открывается **один раз**
для этого семейства; повторная подгонка на нём запрещена. Накопительный счёт попыток: 257 + 1 = **258**.

## Почему
Эксперимент 005 формально отклонён (VALIDATION t = 0.9 < 2.0 при 44 сделках — критерий
рассчитан на частые скальпинг-сделки, у свинга мало сделок и низкая мощность теста). Но:
- 22 из 24 вариантов положительны на DEV, 19 из 24 — на VALIDATION (эффект широкий, не один
  удачный набор параметров);
- версия long/short положительна в **каждом** году 2021–2025 (средняя сделка по всем 12 вариантам:
  111 / 32 / 27 / 22 / 17 / 65 bps) — это не просто рост рынка (long-only в 2022 убыточен);
- есть внешнее подтверждение гипотезы (академические работы о моментуме криптовалют).
Профиль — типичный трендовый: ~44 % выигрышей, прибыль даёт хвост крупных трендов.

## Что проверяется
**Основной кандидат (один):** `H-015-SWING-TSMOM[240m; lookback 28 д; hold 14 д; k=3; long/short]` —
единственный long/short вариант, положительный и на DEV (t 1.9), и на VALIDATION (t 2.1).
Выбор по DEV+VALIDATION смещён вверх — поэтому решение принимается только по HOLDOUT.

**Справочно (не критерий):** среднее всех 12 long/short вариантов на HOLDOUT — показывает,
держится ли эффект семейства без выбора параметров.

## Критерии прохождения (основной кандидат, HOLDOUT, BTC+ETH)
1. средняя чистая сделка > 0 и profit factor ≥ 1.1;
2. средняя сделка > 0 при издержках ×1.5;
3. результат не хуже нуля хотя бы на одном инструменте и суммарно положителен на обоих вместе
   (сделок мало, требовать положительности на каждом по отдельности — слишком шумно);
4. максимальная просадка по капиталу (риск 0.25 % на сделку) < 5 %.

Прошёл → статус **VALIDATION**: переход на демо-счёт вместо технической стратегии `brk4h-fomc`,
с тем же риском 0.25 %; решение о реальных деньгах — не раньше чем через 3 месяца демо и только
владельцем. Не прошёл → REJECTED, семейство закрыто, HOLDOUT считается израсходованным.
