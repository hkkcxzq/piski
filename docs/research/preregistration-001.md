# Предрегистрация эксперимента 001 — первые скальпинг-гипотезы на Bybit

Записано **до** запуска бэктеста. Изменения после просмотра результатов запрещены; любая
доработка — новый эксперимент со своим номером, а число попыток суммируется.

## Данные
- Bybit USDT-perpetual, архив всех сделок `public.bybit.com` → минутные бары с объёмом
  агрессивных покупок/продаж. Инструменты: **BTCUSDT, ETHUSDT**.
- Разбиение (фиксировано):
  - **DEV** (поиск и выбор параметров): 2021-01-01 — 2024-06-30
  - **VALIDATION** (проверка выбранного варианта): 2024-07-01 — 2025-06-30
  - **HOLDOUT** (открывается один раз, только для прошедших VALIDATION): 2025-07-01 — 2026-09-26

## Исполнение и издержки
- Комиссии Bybit base tier: taker 0.055 %, maker 0.02 %; проскальзывание 1 bp на каждое
  рыночное исполнение (вход по рынку, стоп, выход по времени).
- Правила движка пессимистичные (см. `src/quant/backtest/engine.py`): стоп раньше тейка в
  одной свече, лимит исполняется только при проходе цены сквозь уровень, гэп через стоп — по
  открытию, тейк не проверяется в свече входа.
- Не более одной позиции на стратегию и инструмент.
- Размер позиции: риск 0.25 % капитала до стопа, плечо не выше 5x (если стоп слишком близкий —
  плечо ограничивается, риск уменьшается). Это ровно правило владельца «длинный стоп → меньше плечо».
- Фильтр издержек (для всех стратегий): сигналы со стопом ближе 0.25 % от цены пропускаются —
  при таком стопе издержки съедают больше половины риска.

## Гипотезы и сетки параметров
Каждая стратегия проверяется с фильтром активности и без него (`active`: реализованная
волатильность за последний час выше своей медианы за 30 дней).

| ID | Идея | ТФ | Параметры (сетка) |
|---|---|---|---|
| H-001 FVG | Гэп справедливой стоимости (3 свечи): лимитный вход на откате к верхней/нижней границе гэпа, стоп за дальней границей гэпа + 0.1 ATR, тейк R·стоп | 5m, 15m | min_gap ∈ {0.3, 0.6} ATR; R ∈ {1.5, 2.5}; trend ∈ {выкл, EMA50}; expiry 12 баров; max_hold 48 баров |
| H-002 EXH | Выдох после резкого движения: движение за 3 мин > порога σ при объёме > 3× среднего → вход против движения, стоп за экстремумом + 0.25 ATR | 1m | thr ∈ {3, 4.5}σ; R ∈ {1, 2}; max_hold ∈ {15, 60} мин |
| H-003 SQZ | Пробой после сжатия: диапазон N баров < порога от своего среднего за неделю, закрытие за границей с объёмом > 1.5× → вход по пробою, стоп на середине диапазона | 5m | N ∈ {12, 36}; ratio ∈ {0.5, 0.7}; R ∈ {1.5, 3}; max_hold 48 |
| H-004 FLOW | Перекос потока агрессивных ордеров за k минут при объёме > 2× среднего | 1m | k ∈ {5, 15}; |imb| ∈ {0.3, 0.5}; режим ∈ {продолжение, разворот}; стоп 1.5 ATR60, тейк 1.5R, max_hold 30 |

Всего вариантов: FVG 32 + EXH 16 + SQZ 16 + FLOW 16 = **80 попыток**.

## Выбор и критерии
1. **DEV:** для каждой гипотезы выбирается один вариант с максимальной t-статистикой чистой
   доходности сделки (BTC и ETH вместе), при условии ≥ 200 сделок и положительного среднего.
   Если ни один вариант не положителен — гипотеза отклонена на DEV.
2. **VALIDATION** (выбранный вариант, без изменений): средняя чистая сделка > 0 на обоих
   инструментах, общий t ≥ 2.0, profit factor ≥ 1.1, ≥ 50 сделок.
3. **HOLDOUT** (только прошедшие п. 2): средняя чистая сделка > 0, PF ≥ 1.05, и остаётся
   положительной при издержках ×1.5.
4. Прошедшие все три этапа получают статус VALIDATION и идут на Monte Carlo, проверку
   устойчивости параметров и демо-торговлю. Остальные — REJECTED, результаты сохраняются.
